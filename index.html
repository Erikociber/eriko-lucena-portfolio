ipconfig /all

# Testar gateway
ping 192.168.1.1

# Testar conectividade externa

# Testar resolução DNS
nslookup google.com

# Ver o caminho até o destino
tracert google.com

Laboratórios

Prática transforma teoria em evidência. Estes são os tipos de cenários que estou construindo e documentando.

LAB-001

Diagnóstico de conexão de rede

Investigar um computador conectado ao Wi-Fi que não consegue acessar sites.

WindowsTCP/IPDNS
Checklist:
1. Verificar conexão → 2. ipconfig → 3. testar gateway → 4. testar IP externo → 5. testar DNS → 6. documentar causa e solução.
LAB-002

Conta de usuário bloqueada

Simular o atendimento de um usuário que não consegue autenticar no ambiente corporativo.

ADIAMSecurity
Checklist:
Confirmar identidade → verificar domínio → verificar bloqueio/expiração → aplicar procedimento autorizado → registrar atendimento.
LAB-003

Análise de evento no Windows

Praticar a leitura de eventos e identificar comportamentos que merecem investigação.

Event ViewerLogs
Objetivo:
Localizar eventos relevantes, separar informação de alerta e registrar evidências para uma investigação posterior.
